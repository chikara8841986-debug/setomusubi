# せとむすび 介護タクシー事業所向けチラシ

`business-flyer.html` は、A4両面印刷用のチラシです。1ページ目が表面、2ページ目が裏面です。

## 印刷・PDF保存の手順

1. `business-flyer.html` を Google Chrome または Microsoft Edge で開きます。
2. `Ctrl + P` を押して印刷画面を開きます。
3. PDFにする場合は、プリンター欄で「PDFに保存」または「Microsoft Print to PDF」を選びます。
4. 用紙サイズを「A4」、向きを「縦」、倍率を「100%」にします。
5. 余白を「なし」にし、ヘッダーとフッターをオフにします。
6. 「背景のグラフィック」をオンにします。
7. 実際に両面印刷する場合は、プリンターの設定で「両面印刷」と「長辺とじ」を選びます。

このチラシは紙面の端まで使うデザインです。印刷会社へ入稿する場合、または対応プリンターで印刷する場合は、**フチなし・余白なし**を指定してください。フチなし印刷に対応していない家庭用プリンターでは、端に白い余白が出ることがあります。

Google Fontsを使っているため、初めて開くときはインターネット接続が必要です。文字が読み込まれてから印刷してください。読み込めない場合は、游ゴシックまたはメイリオで表示されます。

以下は正式な情報が確認できていないため、仮の表示（黄色の枠）を入れています。**印刷前に必ず正式な内容へ差し替えてください。**

## 未確認の点（印刷前に人の目で確認が必要）

**紙面からのはみ出し（重要）**: 各ページは高さ297mmで固定し `overflow: hidden` を指定しているため、
内容が297mmを超えた場合、**警告なく下端で切れます**。
ブラウザで開いて印刷プレビューを表示し、表面・裏面とも文字が途中で切れていないか必ず目視してください。
（Claudeのブラウザ機能ではこのローカルHTMLが静的スナップショットとして開かれ、CSSと画像が適用されないため、
レイアウトの実測ができませんでした。ソースコード上の指定は正しいことは確認済みです。）

**画像の表示**: ロゴ（`../public/favicon.svg`）と背景写真（`../public/setomusubi-bg.jpg`）は、
このHTMLをファイルとして直接開いたときに正しく解決される相対パスです。ファイルの場所を移動すると表示されなくなります。
