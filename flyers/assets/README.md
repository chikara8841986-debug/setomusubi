# ブランド素材

## `setomusubi-logo.png` — ロゴ（マーク＋ロゴタイプ）

2026-08-23 生成の `flyers/images/user-front.png` から切り出したもの。
**今後のチラシ・資料はこのロゴデザインで統一する**（ユーザー指定）。

特徴:
- マーク: ティール色の波が2本、その上に丸（人／陽）を配した図案。瀬戸内海を表す。
- ロゴタイプ: 「せとむすび」を**丸みのあるゴシック体（丸ゴシック系）**で組んだもの。
  角ばったゴシックではなく、この柔らかい字形を使うこと（ユーザー指定）。
- 色: ティール〜濃紺。

## `setomusubi-mark.png` — マークのみ

ロゴタイプを含まない図案部分だけ。小さく使う場面用。
