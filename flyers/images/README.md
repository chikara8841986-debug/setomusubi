## 既知の制約

**解像度が印刷用としては不足している。**
現状 1054×1492px で、A4に引き伸ばすと約127dpi 相当。
画面表示や家庭用プリンタでの試し刷りは可能だが、印刷会社への入稿品質（300dpi＝2480×3508px）には足りない。
本番の印刷に回す前に、高解像度で再生成するか、アップスケールする必要がある。

**連絡先が未記入。**
裏面2枚の空欄には、正式なURL・電話番号・QRコードが決まってから記入すること。

**3ヶ月無料キャンペーンは決済フローが未対応。**
現在の申込フローは「申込時に初月分を即時決済」のままであり、
`business-front.png` に書かれた「3ヶ月無料」は実装が追いつくまで実態と食い違う。
決済フロー（カード登録のみ先行・課金開始は3ヶ月後）を本番に入れるまで、このチラシを配布してはいけない。

### 画像生成AIとQRコードについて

チラシ本体をAIで画像生成する場合、**QRコードをAIに描かせてはいけない。**
細かい白黒パターンがわずかに崩れるだけで読み取れなくなる。
チラシ画像はQR部分を白い四角の空欄として生成させ、このPNGを後から合成すること。
